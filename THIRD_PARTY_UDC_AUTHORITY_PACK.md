# Third-Party UDC Authority Pack

This pack is a UDC-specific authority/corroboration layer. It is **not** a copy or reconstruction of the licensed UDC Master Reference File (MRF).

## External sources
- Finto UDC Summary: https://finto.fi/udcs/en/
- VocabularyServer UDC Summary: https://vocabularyserver.com/udc/en/
- UDC Consortium subject coverage: https://udcc.org/index.php/site/page?view=subject_coverage

## Priority
1. Licensed/current UDC MRF supplied by the user
2. Current UDC Summary / authorized public UDC data
3. Third-party UDC Summary mirrors, only as corroboration
4. Deterministic current-UDC construction rules
5. Google/Gemini research evidence, never as UDC authority
6. Legacy 1961 material, diagnostic only

## Safety
Do not label a result “UDC reference verified” merely because a web search or language model suggested a number. A current UDC-specific source or licensed MRF must support the notation.
