UDC WORLD TITLE SEMANTIC V10

Purpose
Classify arbitrary book titles against the bundled Universal Decimal Classification B.S. 1000A:1961, Abridged English Edition, 3rd Edition Revised 1961.

Important
This release is source-edition faithful. Do not replace 1961 classmarks with modern UDC numbers. For example, the bundled 1961 index contains China ... history 951, so a title such as "History of China" is resolved to 951 in this edition. Modern UDC may use a different construction.

How it works
1. Exact verified safeguards.
2. Source-driven semantic History/Geography of a named place resolution.
3. Gemini/Groq semantic classification using retrieved pages from the exact uploaded UDC source (when an API key is configured).
4. Offline source-grounded candidate fallback.

Goal
A user can enter titles from any country/topic rather than relying on a small hard-coded list. The engine must understand the whole title and verify notation against the bundled edition.
