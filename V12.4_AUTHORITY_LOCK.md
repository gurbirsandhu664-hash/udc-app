# V12.4 Authority Lock

## The actual fix
The engine now has an explicit **CURRENT_UDC** authority mode.

It does not silently mix:
- current UDC
- the bundled B.S. 1000A:1961 historical edition
- DDC
- arbitrary web snippets

### Pipeline
Title → semantic head concept → candidate notation → current-UDC authority check → notation/facet audit → final answer.

### Important
The complete UDC MRF is licensed. This ZIP therefore does not pretend that its small public seed is the complete MRF.

To obtain truly broad exact coverage, import a legally obtained current UDC MRF/authorized machine-readable reference into `CURRENT_UDC_REFERENCE.json` or through `/api/reference/import`.

The UDC Consortium identifies the MRF as the definitive authorized UDC database and says MRF use requires a licence. The public UDC Summary is a smaller subset.
