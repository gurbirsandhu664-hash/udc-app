# V12.6 — Google + Gemini UDC Verification Lock

This release adds Google Search grounding to the Gemini classification pass.

## Authority rule

Google and Gemini are **verification/research layers**, not the UDC authority themselves.
The authority order remains:

1. Licensed current UDC MRF, when imported
2. Official UDC Summary / official UDC Consortium evidence
3. Deterministic current-UDC rules whose facets are supported by official evidence
4. Gemini + Google Search as a grounded research layer
5. Legacy 1961 UDC only as archival evidence; never as a current override

## Search lock

Gemini is instructed to prefer official UDC Consortium sources (`udcc.org`) for current UDC evidence. Third-party web results can help discover evidence but cannot by themselves turn a guessed number into an authoritative UDC result.

## Anti-hijack rules

- DDC is rejected.
- Unrelated keyword/index hits cannot become the final number.
- Google/Gemini cannot override an imported licensed MRF/current UDC record.
- If Google/Gemini returns no official UDC evidence and no independent current authority supports the candidate, the candidate is rejected.
- Grounding queries and source URLs are returned in the API result for audit/debugging.

## API

`GET /api/authority/status` now reports `google_gemini_verification_lock: true` and Google Search grounding status.
