# UDC One-Click V45 ULTRA

V45 preserved. The uploaded UDC source is bundled and used as the primary classification authority:
**Universal Decimal Classification, B.S. 1000A:1961, Abridged English Edition, 3rd Edition Revised 1961.**

The app retrieves relevant pages from the bundled UDC text and supplies them to the classification engine. It does not silently replace the uploaded edition with DDC or modern UDC notation.

Start with `npm start`.
