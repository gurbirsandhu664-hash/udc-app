# UDC AI V27

Render-ready UDC AI classifier.

## Render
- Build Command: `npm install`
- Start Command: `npm start`

## Environment Variable
Add:

`GEMINI_API_KEY` = your Gemini API key

Do not put the API key in `server.js` or commit it to GitHub.

## Important
This project uses UDC in its prompt and explicitly tells the AI not to use DDC.
For authoritative classification, verify exact notation against your licensed UDC reference.
