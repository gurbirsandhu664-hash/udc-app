# UDC One-Click V12 — Complete Universal Engine

This build keeps the uploaded V11 project/interface and strengthens classification at the engine level.

## Core algorithm
Complete title -> head concept -> explicit facets -> UDC syntax -> source evidence -> semantic reranking.

Alphabetical index keyword hits are not allowed to override the principal subject.

Examples include History + country, Geography + country, and unrest/disturbance + country.

The complete current UDC contains tens of thousands of subdivisions and is continuously revised; exact universal coverage therefore requires a licensed/current UDC reference dataset. This build does not claim that a finite hard-coded answer key is equivalent to the full UDC schedule.
